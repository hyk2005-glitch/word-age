# 언어 나이 진단기 (word-age)

> 당신은 나이를 말하지 않았습니다. 당신의 단어가 말했습니다.

몇 가지 질문에 답하면, 당신이 쓰는 단어만으로 나이와 세대를 추정하는 인터랙티브 웹 서비스입니다.

**파이콘 한국 2026 · 파이썬 작품 전시전 출품작**

---

## 어떻게 동작하나요

국립국어원 「모두의 말뭉치」의 연도별 신문 말뭉치를 형태소 분석하여, 각 단어가 **언제 처음 등장하고(birth), 언제 정점을 찍고(peak), 언제 사라졌는지(death)** 를 산출합니다.

사용자가 "학창 시절 자주 쓰던 표현"을 고르면, 그 단어들의 정점 연도를 근거로 출생 연도를 역산합니다.

```
추정 출생연도 = 단어의 정점 연도 − 그 질문의 암묵 연령
가중치        = 단어의 sharpness × 질문 신뢰도
→ 가중 중앙값으로 종합, 25~75 백분위를 세대 범위로 제시
```

`삐삐`, `싸이월드`처럼 **정점이 뾰족한 단어일수록** 특정 시기를 강하게 가리키므로 더 큰 가중치를 부여합니다.

## 결과물

1. **언어 나이 진단** — "언어 나이 27세, 예상 세대 1998~2001년생" + 추정 근거 전체 공개
2. **나만의 단어 생몰 그래프** — 전체 어휘 흐름 위에 내 단어와 내 인생 시기를 겹친 개인화 그래프

## 기술 스택

Python · Kiwi · pandas · NumPy · Plotly · Streamlit

## 구조

```
pipeline/   오프라인 배치 (말뭉치 → 분석 산출물)
  01_extract.py    말뭉치 → 연도별 텍스트
  02_tokenize.py   Kiwi → 명사 추출
  03_matrix.py     빈도 행렬 + per-million 정규화
  04_lifecycle.py  생애주기 지표 산출

app/        Streamlit 앱 (산출물만 읽음)
  estimator.py     언어 나이 추정 로직
  matcher.py       서술형 입력 → 단어 매칭
  charts.py        시각화
```

무거운 분석은 **오프라인**에서 미리 처리하고, 앱은 그 산출물(`data/processed/`)만 읽습니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app/main.py
```

## 데이터

말뭉치 원본은 저작권상 저장소에 포함하지 않습니다.

1. [국립국어원 모두의 말뭉치](https://kli.korean.go.kr/corpus)에서 연도별 신문 말뭉치를 신청·다운로드
2. `data/raw/` 폴더를 만들고 그 안에 배치
3. `pipeline/` 스크립트를 순서대로 실행

> 본 프로젝트는 국립국어원 「모두의 말뭉치」를 활용하였으며, 말뭉치 원문은 재배포하지 않고 통계·시각화 결과만 사용합니다.
